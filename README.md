# Mafsar — turn AI chats into study material

A Chrome (MV3) extension that captures your learning conversations with AI
assistants (ChatGPT, Claude) and turns them into **flashcards**, a
**multiple-choice quiz**, and **spaced-repetition reviews** — so you don't
forget what you learned by talking to an agent.

Everything runs locally in your browser. Study material is generated by an LLM
provider of your choice using **your own API key** — pick a **free** provider
(Google Gemini or Groq) or paid Anthropic Claude in settings. Nothing is sent to
any server other than the provider you choose.

## Install (load unpacked)

1. Open `chrome://extensions`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and select this `mafsar/` folder.
4. Click the extension's **Details → Extension options** (or the ⚙ in the panel),
   choose a provider, and paste your API key. **Google Gemini** is free and
   recommended — get a key at
   [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey). Save.

> Note: no toolbar icon image is bundled yet, so Chrome shows a default puzzle
> piece. Drop 16/48/128px PNGs in `icons/` and add an `"icons"` block to
> `manifest.json` to brand it.

## Use

1. Open a conversation on **chatgpt.com** or **claude.ai** and learn something.
2. Click the floating **📚 Save to Mafsar** button (bottom-right of the page),
   or open the side panel and hit **Capture current chat**.
3. Open the side panel (click the toolbar icon), pick the saved session, and
   click **Make study set**. Mafsar asks Claude to extract the key knowledge and
   build flashcards + a quiz.
4. Review flashcards (grade Again/Hard/Good/Easy — SM-2 schedules the next
   review) and take the quiz. Come back later; due cards resurface first.

## Project layout

| Path | Role |
|------|------|
| `manifest.json` | MV3 manifest, permissions, content-script registration |
| `src/content/adapters/*` | Per-site DOM readers (`chatgpt.js`, `claude.js`) behind a shared registry |
| `src/content/capture.js` | Injects the Save button; reads the chat via the active adapter |
| `src/background/service-worker.js` | Message router; stores captures; runs generation |
| `src/llm/generate.js` | Builds the prompt, calls the Anthropic API, parses JSON |
| `src/storage/store.js` | `chrome.storage.local` wrapper (settings, sessions, study sets) |
| `src/storage/srs.js` | SM-2 spaced-repetition scheduling |
| `src/ui/panel.*` | Side panel: sessions, flashcard review, quiz |
| `src/ui/options.*` | API key + model settings |

## Maintenance note

The **adapters** are the fragile part: chat sites change their HTML periodically.
If capture stops working on a site, the fix is almost always isolated to that
site's file in `src/content/adapters/`. Each adapter is just a `matches()` test
plus a `getMessages()` that returns `[{ role, text }]`.

## Roadmap

- Export/import study sets; cross-device sync.
- More sites (Gemini, Perplexity) — just add an adapter.
- Hosted backend option so users don't need their own API key.
